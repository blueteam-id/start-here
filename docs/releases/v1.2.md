# v1.2: All 13 tracks live, plus a roadmap (2026-11-24)

Every track in the program is now live: **13 tracks, about 30 hours**, from
how a computer works to running your own server and understanding AI. The
homepage has a new roadmap showing where to start and where to go next, and
the five original tracks got a round of fixes and clearer writing.

If you are partway through a track, your progress is kept.

## Eight new tracks

| Track | Lessons | What you do |
| --- | --- | --- |
| **Networking Fundamentals** | 5 | Find your own addresses, work out subnets by hand, list the ports open on your machine, follow a packet with `traceroute`, and map your own connection. |
| **Security Concepts** | 5 | The CIA triad, threat versus risk, hashing and encryption, ethics and the law (including Indonesia's UU ITE and UU PDP), and a first forensic timeline of your own computer. |
| **How the Web Really Works** | 5 | URLs, HTTP with `curl`, building a small web page, cookies and sessions, and tracing one page load end to end. |
| **Programming Basics (Python)** | 6 | From a first script to a TCP socket, ending with a tool that reads a real SSH log and flags a break-in. |
| **SQL Basics** | 5 | Query a practice database in DB Browser for SQLite, then investigate one suspicious night at a fictional company. |
| **Servers & Services** | 6 | Build an Ubuntu Server lab VM, then set up SSH keys, nginx, and MariaDB, read the logs, and harden it with a firewall. |
| **AI Fundamentals** | 5 | What machine learning really is, how models learn and fail, precision and recall, and how to use AI safely at work. |
| **How LLMs Actually Work** | 5 | Tokens, embeddings, and next-token prediction, then prompt injection, jailbreaks, data leakage, and AI agents. |

The new tracks start at version 1.0. Some include downloadable practice files
(a sample SSH log and a practice database), each shown with its SHA-256 hash.

## A roadmap on the homepage

The homepage now shows every track as a six-step path, plus an AI lane you can
take anytime. Each step links to its track. Once you start, it marks finished
tracks and highlights what to take next, using only your own browser's saved
progress.

## Fixes to the first five tracks (now v1.1)

**Git Fundamentals**
- New repositories now start on `main`, so later `git switch main` commands
  work on every install.
- Windows learners now use **Git Bash**. In Windows PowerShell, `echo > file`
  saved files as UTF-16 and `git diff` showed "Binary files differ".
- Recommends a GitHub/GitLab **noreply email**, so your personal address is
  not published in commit history.
- Explains how to quit the pager (`q`), how to edit a file with `nano` during
  a merge conflict, and how to leave Vim if it opens.

**GitHub/GitLab Fundamentals**
- New "sign in once" step before the first push. GitHub no longer accepts
  account passwords over HTTPS.
- The practice repository is now **public**, because branch protection is only
  enforced on public repositories on GitHub's free plan.
- Branch protection uses 0 required approvals for practice, since you cannot
  approve your own pull request.

**Windows Foundations**
- The Event Viewer lesson explains that the Security log needs an
  administrator prompt.
- The wrap-up exercise writes only to a practice registry key and adds a check
  for Event ID 1102 (log cleared).
- Points to the 90-day Windows 11 evaluation download, with a note for Apple
  Silicon Macs.

**Linux Essentials**
- New: getting help with `man` and `--help`, a read-only tour of `/etc`,
  `/var/log`, and `/tmp`, editing with `nano`, watching a log live with
  `tail -f`, and reading accounts from `id` and `/etc/passwd`.
- Track time updated from 160 to 180 minutes.

**All five tracks**
- Rewritten in shorter, plainer sentences for readers using English as a
  second language. Every command is unchanged.
- Clear boxes for warnings, Windows-only steps, and "if it didn't work" tips,
  plus "You should see" blocks for expected output.
