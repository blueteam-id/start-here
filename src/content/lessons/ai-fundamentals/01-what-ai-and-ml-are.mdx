## Four words, from widest to narrowest

- **Artificial intelligence (AI)** is the widest term: computer systems doing tasks that normally need human judgment, such as recognizing images, understanding language, or deciding what is suspicious. It says nothing about **how** they do it.
- **Machine learning (ML)** is one way to build AI: instead of writing the rules by hand, you show the computer many examples and let it **learn** the patterns.
- **Deep learning** is a kind of machine learning that uses large **neural networks**, layers of simple maths units loosely inspired by brain cells. It powers modern image and speech recognition.
- **Generative AI** is deep learning that **produces** new content: text, images, code, audio. Chat assistants are built on **large language models** (LLMs), the subject of the next track.

Each is a part of the one before it: generative AI is deep learning, deep learning is machine learning, and machine learning is one way to do AI.

## Rules versus learning

The key difference between "classic" software and machine learning is who writes the logic:

- **Rule-based**: a person writes the rules. "If the email contains 'you won' and a link, mark it as spam." Easy to explain; misses anything the rule writer did not think of.
- **Learned**: a person collects thousands of emails labeled spam or not spam, and a learning algorithm finds the patterns. Catches patterns no person would have written down; harder to explain why it decided something.

Many real products mix both. And many products called "AI" are mostly rules, which is not a bad thing, just worth knowing.

## A model is a function

A **model** is the result of learning: a function that takes an input and gives an output, like the functions in the Python track. A spam model takes an email and returns "spam" or "not spam", usually with a **confidence** score between 0 and 1. The model does not "understand" email the way you do. It has learned which patterns tended to come with which label in the examples it saw.

### What to notice

- AI is the goal; machine learning is learning from examples; deep learning uses neural networks; generative AI creates content.
- Rule-based systems are explainable but limited; learned systems find patterns nobody wrote down, but are harder to explain.
- A model is a learned function with a confidence score, not understanding.
- "AI-powered" alone tells you nothing. Ask about the data and the output.
