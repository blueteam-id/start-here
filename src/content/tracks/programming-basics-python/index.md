This track teaches enough Python to automate a boring check and to read other people's scripts. Six lessons cover your first script, variables and input, decisions and loops, functions, files and dictionaries, and a first network connection with a TCP socket. Every lesson adds a piece of one small tool: by the end you have a script that reads a real SSH log and flags a likely break-in.

You need Python 3, installed once from python.org (macOS and most Linux systems already have it). Everything uses only what comes with Python, so there is nothing else to install. All files stay in one practice folder.

Python is the language most security tools and automation are written in. You do not need to become a programmer, but reading and writing small scripts is an everyday skill. When a question goes beyond the lessons, bring it to the community Discord.
