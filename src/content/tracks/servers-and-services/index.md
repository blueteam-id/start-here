This track puts you on the other side: running the services that everything else in the program talks to. Six lessons take you from building a lab server, through remote access with SSH, a web server, and a database server, to how DNS, mail, and logs work on a server, and finally to a first round of hardening.

It needs a **virtual machine**. You build one in the first lesson: Ubuntu Server inside VirtualBox, or UTM on an Apple Silicon Mac, with a snapshot so you can always roll back. Inside that VM, and only there, you use `sudo` freely: it is your own disposable server.

The VM stays private to your computer, so nothing you run is exposed to the internet. This is the track where the earlier ones come together: Linux, networking, the web, SQL, and the security habits. When a question goes beyond the lessons, bring it to the community Discord.
