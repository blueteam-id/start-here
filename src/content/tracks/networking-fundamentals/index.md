This track explains how computers find each other and talk. Five lessons cover your own network, IP addresses and subnets, ports with TCP and UDP, and the trip a packet takes from your laptop to a website. You finish by mapping your own connection, end to end.

Every lesson is hands-on with tools already built into macOS, Linux, and Windows, and every command only looks; nothing changes your settings. Windows users should run this track in PowerShell, not WSL: WSL sits behind its own small virtual network, so it would show you that instead of your real one. One optional step uses Wireshark, a free install, and is clearly marked.

Almost every security alert names an address, a port, or a domain. This track is what lets you read those alerts. When a question goes beyond the lessons, bring it to the community Discord.
