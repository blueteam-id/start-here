This track picks up exactly where Git Fundamentals leaves off: your code now needs to live somewhere shared, get reviewed by other people, and run automatically through CI. Five lessons cover remotes, forks and pull/merge requests, code review as a real security control, access control and secrets, and the basics of CI, using GitHub as the primary example, with GitLab's equivalent terms noted throughout since the underlying ideas are the same on either platform.

Hands-on here needs one thing the earlier tracks didn't: a free account on GitHub or GitLab, created in the first lesson if you don't already have one. Everything after that uses only the free tier.

These platforms host almost all of the world's source code, open source and corporate alike, which makes them one of the highest-value targets in the entire software supply chain. Understanding how access, review, and automation actually work here isn't optional background for a security career, it's daily-use knowledge.
