This track is about Git, the version control tool that quietly runs underneath almost everything a modern security team touches: infrastructure-as-code, detection rules, internal tooling, and the open-source software everyone depends on. Five lessons take you from your first commit to confidently branching, merging, and undoing a mistake without losing work or quietly erasing the record of what happened.

Every lesson is hands-on, in one small practice folder on your own machine. Nothing here needs an account on any website, that's the next track, Git Fundamentals only needs Git itself, which is free and runs identically on Windows, macOS, and Linux.

Git history is also, whether anyone planned it that way or not, a forensic record: who changed what, and when. Understanding Git well is what lets you read that record instead of just working around it. When something here raises a question the lessons don't answer, take it to the community Discord.
